# 🎬 IMDB Movie Review Sentiment Analysis

A **Sentiment Analysis** machine learning project that classifies **IMDB movie reviews** as **Positive 😊** or **Negative 😞**.  
This project covers the complete ML pipeline — from text preprocessing and model training to **deployment on Hugging Face Spaces**.

🚀 **Live Demo (Hugging Face):**  
👉 https://huggingface.co/spaces/AnukulChandra/Se

---

## 📌 Project Overview

Sentiment analysis is a fundamental task in Natural Language Processing (NLP).  
This project analyzes movie reviews from the IMDB dataset and predicts whether a given review expresses a **positive** or **negative** sentiment using machine learning techniques.

The trained model is deployed as an interactive web application on **Hugging Face Spaces** for real-time inference.
